美参议院68:30票通过GENIUS法案，联邦稳定币监管框架确立

法案要求稳定币发行方持有1:1美元或短期国债储备（≤93天到期），月度披露储备明细，年度审计。算法稳定币被明确禁止。破产时持有者享有优先偿付权。18名民主党跨党投票支持。
So What：稳定币从监管灰色地带正式纳入联邦框架，合规发行方（Circle、Paxos）获结构性优势。银行业仍在博弈收益条款——后续众议院与《清晰法案》衔接是关键节点。

CFTC拟将非托管钱包开发者保护正式写入规则

CFTC主席Michael Selig在Consensus大会上宣布，将把此前对Phantom发出的无行动函（免注册经纪商）升级为正式规则制定，明确自托管钱包软件开发者无需注册。SEC上月已发类似指导。
So What：从临时性豁免升级为永久性规则，美国DeFi基础设施开发者的合规不确定性大幅降低。利好MetaMask、Phantom等非托管钱包的美国业务。
监管

银行业协会反击：称《清晰法案》稳定币收益妥协条款仍有漏洞

美国银行家协会等五大行业组织联合声明，认为Tillis-Alsobrooks稳定币收益折中文本"未能充分阻止稳定币模仿银行存款利息"，将在数日内提交修改建议。此前该妥协令Coinbase涨6%、Circle涨20%。
So What：立法进程未结束。银行业游说力量仍在试图收紧条款，如果最终文本进一步限制收益分配，DeFi收益产品将面临合规压力。

Anthropic发布面向银行/资管/保险的10款预构建AI Agent，覆盖客户推介、财报审阅、合规升级等场景，自主执行并生成完整审计轨迹。同步发布Claude Opus 4.7——针对金融任务优化的最强模型。紧随$15亿Blackstone/Goldman合资之后。FactSet一度跌8%、Morningstar跌逾3%。
So What：AI从"辅助对话"转向"自主执行"金融工作流。数据/研究类SaaS（FactSet、Morningstar）面临被Agent替代的直接威胁。OpenAI×PwC vs Anthropic×Goldman——金融AI军备竞赛正式双线展开。

摩根士丹利E*Trade正式上线现货加密交易

Morgan Stanley于5月6日在E*Trade平台正式开放加密现货交易试点，首批支持BTC、ETH、SOL，收取50bps交易费。基础设施由Zerohash提供。此前其BTC ETF首周即吸引$1亿资产。
So What：传统券商零售端入场的标志性事件。50bps费率大幅低于Coinbase Pro，直接冲击加密原生交易所的零售份额。E*Trade用户基数约500万——即便5%转化也是巨大增量。

BNY纽约银行联手Finstreet×ADI，在阿布扎比推出机构级BTC/ETH托管

管理$59万亿资产的全球最大托管银行BNY，与Finstreet及ADI Foundation合作，在ADGM（阿布扎比全球市场）部署受监管数字资产托管服务，初期聚焦BTC和ETH，后续扩展至稳定币和代币化资产。
So What：全球最大托管行进入中东数字资产市场——信号意义巨大。阿联酋正加速构建"全球加密金融枢纽"叙事，与新加坡/香港形成三足鼎立竞争格局。

Broadridge×Galaxy：美国上市公司首次链上代理投票实战

Broadridge将ProxyVote平台扩展至代币化证券，Galaxy Digital将在5月股东大会上成为首家使用链上代理投票的美国上市公司。平台整合传统股东+代币化持仓为"单一视图"。Broadridge每月已处理$8万亿代币化资产。
So What：治理层是代币化股权大规模采用的最后一块拼图。Broadridge作为全球最大代理投票基础设施商介入，标志着链上公司治理从概念走向机构级生产环境。
